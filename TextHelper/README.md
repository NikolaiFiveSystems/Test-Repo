# TextHelper — проверка орфографии и переформулировка в любой программе Windows

Выделяете текст в любом окне (мессенджер, почта, браузер, Word, 1С…) и нажимаете:

| Клавиши | Что делает | Чем |
|---|---|---|
| **Ctrl+Alt+F** | Сразу исправляет орфографию и грамматику, во всплывающей подсказке показывает, что исправлено | [LanguageTool](https://languagetool.org), бесплатно, без ключей |
| **Ctrl+Alt+R** | Открывает меню: *Исправить ошибки · Переформулировать · Вежливее · Ответ пользователю · Для коллеги · Инструкция по шагам · Проще · Короче · Подробнее · Перевести на английский* → окно с результатом → **Enter** заменяет текст | GigaChat (по умолчанию), локальная модель через Ollama или Claude |

Сделано на [AutoHotkey v2](https://www.autohotkey.com). Это и есть «Tampermonkey для рабочего стола»: скрипты, которые работают в любой программе Windows.

## Установка (5 минут)

1. Установите **AutoHotkey v2** с [autohotkey.com](https://www.autohotkey.com) (кнопка *Download v2.0*).
2. Скачайте папку `TextHelper` целиком (на GitHub: *Code → Download ZIP*) и распакуйте в любое место, например в `Документы\TextHelper`.
3. Дважды щёлкните `TextHelper.ahk`. В трее появится значок **H**.
4. Чтобы скрипт запускался сам: правый клик по значку → **Запускать вместе с Windows**.

Проверка орфографии (**Ctrl+Alt+F**) работает сразу. Для переформулировки (**Ctrl+Alt+R**) нужна языковая модель, её настройка описана ниже.

## Языковая модель для переформулировки

Модель выбирается строкой `Provider=` в разделе `[General]` файла `settings.ini` (правый клик по значку → **Настройки**). После изменения настроек нажмите **Перезапустить** в меню значка.

### 1. GigaChat (по умолчанию): доступен в РФ, есть бесплатный пакет

1. Зарегистрируйтесь на [developers.sber.ru](https://developers.sber.ru) и создайте проект **GigaChat API**. Физлицам доступен бесплатный пакет токенов (Freemium), текущий объём указан в личном кабинете.
2. В настройках API проекта нажмите **Получить ключ** и скопируйте **Ключ авторизации** (Authorization key).
3. Вставьте ключ в `settings.ini`:
   ```ini
   [GigaChat]
   AuthKey=ваш_ключ_авторизации
   ```
4. Сертификат ставить не нужно. Серверы Сбера используют сертификат НУЦ Минцифры, которому Windows по умолчанию не доверяет, поэтому для GigaChat проверка сертификата выключена (`VerifySsl=0`, как `verify=False` в SDK Сбера). Остальные сервисы проверяются как обычно. Если хотите включить проверку, установите **«Russian Trusted Root CA»** с [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt) и поставьте `VerifySsl=1`.

Модель меняется в строке `Model=`: `GigaChat-2` работает быстрее и даёт больше бесплатных токенов, `GigaChat-2-Pro` и `GigaChat-2-Max` пишут лучше.

### 2. Локальная модель (Ollama): бесплатно, без интернета и регистрации

Текст никуда не отправляется, всё считается на вашем компьютере. Для модели на 7–8 млрд параметров желательно 16 ГБ ОЗУ или видеокарта с 8 ГБ памяти. На слабом ПК работает медленно.

1. Установите [Ollama](https://ollama.com).
2. В командной строке выполните: `ollama pull qwen2.5:7b`
3. В `settings.ini` укажите `Provider=local`.

Подойдёт и **LM Studio** или любой сервис с OpenAI-совместимым API: в разделе `[Local]` укажите адрес `…/v1/chat/completions`, модель и ключ.

### 3. Claude (Anthropic): платно, официально недоступен в РФ

`Provider=claude` и ключ из [platform.claude.com](https://platform.claude.com) в разделе `[Claude]`. По умолчанию используется `claude-opus-5-5`. Включён `Fallbacks=default`: если модель откажется отвечать, запрос автоматически повторится на рекомендованной резервной модели.

## Как пользоваться

- **Выделите текст** и нажмите горячую клавишу. Если ничего не выделено, появится подсказка. Можно включить `SelectAllIfEmpty=1`, тогда скрипт сам выделит всё поле ввода (удобно в мессенджерах).
- В меню **Ctrl+Alt+R** пункт можно выбрать цифрой: `Ctrl+Alt+R`, затем `2`.
- В окне результата текст можно поправить вручную:
  - **Enter** — заменить выделенный текст;
  - **Ещё вариант** — попросить модель написать иначе;
  - **Копировать** — только скопировать результат;
  - **Esc** — отмена.
- Любую замену можно откатить сочетанием **Ctrl+Z** в той программе, где был текст.
- Буфер обмена после работы восстанавливается.

## Свои команды

Раздел `[Actions]` в `settings.ini` задаёт пункты меню в формате `Название=Задание для модели`. Например:

```ini
[Actions]
Ответ клиенту=Перепиши как вежливый ответ клиенту от службы поддержки, коротко и по делу.
Без ошибок и смайликов=Исправь ошибки и убери эмодзи. Больше ничего не меняй.
```

## Контекст и словарь терминов

Оба файла лежат рядом со скриптом и открываются из меню значка в трее. Изменения применяются сразу, перезапуск не нужен.

- **`context.txt`** — кто вы и о чём пишете. Текст уходит модели вместе с каждым запросом: так она понимает термины и подбирает тон. По умолчанию там описан технический специалист по 1С, ККТ, маркировке, ЕГАИС и торговому оборудованию; перепишите под себя.
- **`dictionary.txt`** — термины, которые нельзя «исправлять»: проверка орфографии их пропускает (в том числе с другими окончаниями: Рутокен → Рутокена), а модель сохраняет как написано. Аббревиатуры (ККТ, ЕГАИС), слова с цифрами (1С, 54-ФЗ, COM1) и идентификаторы вида `ПолучитьДанные` проверка орфографии пропускает и без словаря.

Строки, начинающиеся с `;`, в обоих файлах — комментарии.

## Горячие клавиши

Горячие клавиши задаются в разделе `[Hotkeys]`: `^` = Ctrl, `!` = Alt, `+` = Shift, `#` = Win. Клавиши записаны кодами (`vk46` = F, `vk52` = R), поэтому срабатывают при любой раскладке, в том числе в русской.

## Куда уходит текст

- **Ctrl+Alt+F** отправляет выделенный текст на сервер LanguageTool (`api.languagetool.org`, Европа). Бесплатный сервис ограничен примерно 20 запросами в минуту и 20 КБ текста за раз. Можно поднять собственный сервер LanguageTool и указать его в `Url=`.
- **Ctrl+Alt+R** отправляет текст выбранной модели: Сберу (GigaChat), Anthropic (Claude) или никуда (локальная модель).
- Не обрабатывайте так тексты, которые нельзя передавать третьим лицам. Для них есть локальная модель.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Горячая клавиша не срабатывает | Возможно, сочетание занято другой программой. Поменяйте его в `[Hotkeys]`. В программах, запущенных от администратора, скрипт тоже нужно запускать от администратора. |
| Текст не заменился | Некоторые программы медленно забирают текст из буфера. Повторите попытку или нажмите **Копировать** и вставьте результат вручную. |
| «Сертификат, которому Windows не доверяет» | Для GigaChat поставьте `VerifySsl=0` или установите сертификат Минцифры (см. раздел про GigaChat). |
| «Запущена ли Ollama?» | Запустите Ollama и проверьте, что модель скачана (`ollama list`). |
| Корпоративная сеть с прокси | Укажите `Proxy=адрес:порт` в разделе `[General]`. |

## Для разработчиков

- `TextHelper.ahk` — горячие клавиши, меню, окно результата, трей.
- `lib/Services.ahk` — LanguageTool, GigaChat, OpenAI-совместимые модели, Claude.
- `lib/Net.ahk` — HTTP через WinHTTP с UTF-8, `lib/Json.ahk` — разбор JSON.
- Тесты: `AutoHotkey64.exe /ErrorStdOut tests\RunTests.ahk` выводит результат в консоль, код выхода 0 означает, что всё прошло.
